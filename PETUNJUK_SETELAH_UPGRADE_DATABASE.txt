PETUNJUK MENJALANKAN PROYEK SETELAH DATABASE DI-UPGRADE

1. Letakkan folder pwb_2422500010 di C:\\xampp\\htdocs\\
2. Pastikan database MySQL bernama pwb_2422500010 sudah berhasil di-upgrade.
3. Periksa application/config/database.php:
   hostname=localhost, username=root, database=pwb_2422500010.
   Sesuaikan password jika MySQL lokal Anda menggunakan password.
4. Jalankan Apache dan MySQL dari XAMPP.
5. Buka http://localhost/pwb_2422500010/
6. Buka Register, isi semua kolom, lalu daftar.
7. Login dengan email dan password yang baru didaftarkan.
8. Setelah login, pilih menu Profil. Profil menampilkan data pelanggan aktif.
9. Pilih Logout untuk mengakhiri sesi.

CATATAN:
- Struktur database pelanggan mengikuti hasil SQL Upgrade:
  id_pelanggan, email, password, nama_pelanggan, telp_pelanggan,
  alamat, kota, kode_pos, provinsi.
- Form HTML tetap memakai nama input nama dan telepon; controller memetakan
  nilainya ke kolom database nama_pelanggan dan telp_pelanggan.
- Password pelanggan baru disimpan menggunakan password_hash().
- Pelanggan lama yang belum memiliki password harus melakukan registrasi akun
  baru atau dibantu pengisian password secara aman sebelum dapat login.
- Jangan impor ulang SQL database lengkap di atas database lama.
